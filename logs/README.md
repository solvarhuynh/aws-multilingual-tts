# Nhật ký làm việc

Mỗi thành viên dùng một file `log-m<số>.md` theo module mình phụ trách. Đầu mỗi buổi, AI đọc lại file này cùng với `AGENTS.md`.

Cuối buổi, ghi đè khối **TRẠNG THÁI NHANH**. Mục nhật ký mới được thêm lên trên cùng trong phần **NHẬT KÝ**.

Mỗi mục nhật ký ghi ngày giờ, việc đã làm, file đã đổi, tài nguyên AWS đã tạo hoặc sửa, quyết định và lý do, lỗi hoặc việc còn dở, việc tiếp theo và điều cần báo module khác. Dùng mẫu ở mục 7 của `AGENTS.md`.

Không ghi key, mật khẩu hoặc token vào nhật ký.

## Mẫu mục nhật ký

```markdown
### YYYY-MM-DD HH:MM: Tên việc ngắn gọn
- Đã làm:
- File đã đổi:
- Tài nguyên AWS đã tạo/sửa (tên, region):
- Quyết định và lý do:
- Lỗi gặp / đang dở:
- Việc tiếp theo:
- Cần báo module khác:
```

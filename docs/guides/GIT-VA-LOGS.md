# Git và nhật ký

- Nhánh `main` luôn ở trạng thái có thể chạy được.
- Mỗi việc làm trên một nhánh riêng, ví dụ `m2/synthesize-polly`.
- Đặt tên commit theo mẫu `[M2] mô tả ngắn`.
- Gộp vào `main` bằng Pull Request; tự chạy thử trước khi gộp. Không cần chờ duyệt, nhưng thay đổi quy ước chung phải báo cả nhóm.
- Không commit key, mật khẩu hoặc file `.env`.
- Đầu buổi, đọc `AGENTS.md`, nhật ký module và file task. Cuối buổi, cập nhật khối trạng thái nhanh và thêm mục nhật ký mới lên đầu.

Câu mở đầu mẫu:

> Tôi là thành viên M2. Hãy đọc AGENTS.md, logs/log-m2.md và docs/tasks/task-m2.md, rồi tóm tắt cho tôi đang làm đến đâu.
